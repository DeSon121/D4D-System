# D4D (Desk 4 Dudes) - Campus IT Help Desk

A 3-tier help desk and ticket management system built with Node.js, Express, React, Vite, and PostgreSQL.

## Tech Stack
- **Frontend:** React, Vite (Port 5173)
- **Backend:** Node.js, Express (Port 5000)
- **Database:** PostgreSQL (`d4d_db`)

## Getting Started

### 1. Backend Setup
```bash
cd server
npm install
# Create a .env file with PORT=5000, DATABASE_URL, and JWT_SECRET
npm run dev
